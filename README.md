# Calculadora Simple

Una calculadora interactiva en Python que permite realizar operaciones aritméticas básicas.

## Funcionalidades

- **Suma**: Suma dos números
- **Resta**: Resta el segundo número del primero
- **Multiplicación**: Multiplica dos números
- **División**: Divide el primer número entre el segundo (con validación de división por cero)

## Cómo usar

Ejecuta el programa:

```bash
python calculadora.py
```

Luego selecciona la operación que desees realizar (1-5) e ingresa los números cuando se te pida.

## Requisitos

- Python 3.x
